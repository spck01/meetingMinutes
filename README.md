# スパチキ議事録メーカー

会議の録画・録音ファイルをドラッグ&ドロップするだけで、**文字起こし（Whisper）→ 議事録（GPT）** まで自動で作るWebアプリです。
Discordでの会議を想定し、議事録をそのままDiscordに貼り付けられるコピー機能も付いています。

## 主な機能

- 動画・音声ファイルのドラッグ&ドロップ（MP4 / MOV / MKV / WebM / MP3 / M4A / WAV など、最大2GB）
- 動画から音声を自動抽出し、10分ごとに分割して文字起こし（タイムスタンプ付き）
- 「会議概要・決定事項・ToDo・議論の要点・保留事項」の形式で議事録を生成
- 議事録 / 文字起こしのコピー・ダウンロード
- **Discord用にコピー**：表を箇条書きに変換し、2,000文字を超える場合は複数メッセージに分割

## 必要なもの

- Python 3.12 以上
- OpenAI APIキー

ffmpegは `imageio-ffmpeg` に同梱されたものを使うため、別途インストールは不要です。

## セットアップ

```powershell
git clone <このリポジトリのURL>
cd meetingMinutes
python -m venv venv
.\venv\Scripts\python -m pip install -r requirements.txt
```

APIキーは次のどちらかで設定します。

- `.env.example` を `.env` にコピーして `OPENAI_API_KEY` を記入する
- 起動後、画面右上の「設定」から入力する（ブラウザにのみ保存されます）

## 起動

```powershell
.\venv\Scripts\uvicorn server:app --port 8000
```

ブラウザで http://localhost:8000 を開きます。

## 設定（`.env`）

| 変数 | 既定値 | 説明 |
|---|---|---|
| `OPENAI_API_KEY` | なし | OpenAI APIキー |
| `TRANSCRIBE_MODEL` | `whisper-1` | 文字起こしモデル。`whisper-1` 以外ではタイムスタンプが10分単位になります |
| `MINUTES_MODEL` | `gpt-5-mini` | 議事録生成モデル |

議事録のフォーマットを変えたい場合は `core.py` の `MINUTES_PROMPT` を編集してください。

## 料金の目安

`whisper-1` での文字起こしは1時間あたり約 $0.36 です。議事録生成はそれより十分安く収まります。

## ファイル構成

```
core.py            音声抽出・文字起こし・議事録生成の処理
server.py          FastAPIサーバー（アップロード受付・進捗API）
static/index.html  画面
```

## 注意事項

- **認証機能はありません。** ローカルでの個人利用を前提としています。インターネットに公開すると、第三者があなたのAPIキーで処理を実行できてしまうため、公開する場合は認証を追加してください。
- 録画データは処理後にサーバーから削除されます。処理の状態はメモリ上にのみ保持され、サーバーを再起動すると消えます。
- 音声が1本にまとまっているため、話者の識別は行いません。補足情報欄に参加者名を書くと、発言内に名前が出てくる場合に議事録へ反映されやすくなります。
- 会議の録画や生成した議事録はリポジトリにコミットしないでください（`.gitignore` で主な形式は除外済み）。
